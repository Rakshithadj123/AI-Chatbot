# AI Chatbot 🤖

## Project Description
AI Chatbot is a conversational application built using Python and Streamlit. It allows users to interact with an AI language model and receive responses to their questions.

## Technologies Used
- Python
- Streamlit
- Ollama
- Large Language Models (LLMs)

## Features
- Interactive chatbot interface
- Real-time conversations
- Local AI model integration using Ollama
- Chat history
- Clear chat option

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Rakshithadj123/AI-Chatbot.git
```

2. Open the project folder:
```bash
cd AI-Chatbot
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Make sure Ollama is installed and your required model is downloaded.

## Run the Application
```bash
streamlit run app.py
```

## Project Goal
To build a simple, interactive AI chatbot using free and locally running language models.
